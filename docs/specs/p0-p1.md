# Spec P0+P1 — Scaffold, Design-Tokens, Layout-Shell, Modul-Schema, 6-Schritt-Renderer

*Autor: Fable (Hauptsession). Umsetzung: builder (Opus 4.8). Diese Spec ist verbindlich — bei Unklarheit stoppen und zurückmelden, nicht raten.*

## Regeln für den builder

- **Nutzertexte:** Jeder sichtbare Text kommt wörtlich aus dieser Spec oder aus `content/*.json`. Du formulierst nichts selbst, du änderst nichts (auch keine Satzzeichen). Fehlt ein Text, baue `TODO(fable)` ein und melde es.
- **Nicht anfassen:** `content/` (nur lesen), `wissensfundus/`, `konzept/`, `research/`, `CLAUDE.md`, `README.md`, `KICKOFF.md`, `.env`, `docs/`.
- **Dependencies:** nur `next@15`, `react`, `react-dom`, `typescript`, `tailwindcss` v4 + `@tailwindcss/postcss`, `@types/*`, `eslint` + `eslint-config-next`, `@fontsource-variable/fraunces`, `@fontsource-variable/source-sans-3`. Nichts weiter ohne Rückmeldung.
- **Commits:** klein und benannt, Präfix `feat(p0):` / `feat(p1):`, z.B. `feat(p0): scaffold + design-tokens`, `feat(p1): modul-renderer schritt-navigation`.
- **Definition of Done:** `npm run build` und `npm run lint` grün; `/` und `/modul/s1` funktionieren mobil (375 px) und Desktop; keine Konsolen-Fehler.

## P0 — Scaffold, Design-Tokens, Layout-Shell

### Scaffold

Next.js 15 (App Router) + TypeScript (strict) + Tailwind v4, direkt im Repo-Root (`app/`, `components/`, `lib/` auf oberster Ebene, kein `src/`). Die bestehenden Markdown-Ordner bleiben unberührt. Pfad-Alias `@/*` auf Repo-Root. `resolveJsonModule: true`.

Routen (P0 als Gerüst, P1 füllt sie):
- `/` — Home mit Modul-Landkarte
- `/modul/[id]` — Modul-Player
- `/mein-weg` — Mein Weg
- `/hilfe` — Hilfe in Krisen
- `not-found` — 404

### Metadata (app/layout.tsx)

- `lang="de"`
- Titel: `Gebrauchsanweisung zum Menschsein`
- Description: `Ein ruhiges Selbstlernprogramm der Mind-Body-Medizin: verstehen, erleben, in den Alltag bringen.`
- `themeColor`: `#FAF6EF` (light) / `#221F1A` (dark)

Gestaltungsregeln (verbindlich):
- Fließtext ≥ 18 px, Zeilenhöhe ≥ 1.6, Absatzabstand großzügig; Lesebreite max. ~65ch.
- Überschriften: Fraunces, ruhig, keine Versalien-Schreie.
- Karten: `rounded-2xl`, Fläche `flaeche`, 1px Rand `linie`, weicher Schatten oder keiner.
- Übergänge 200–400 ms `ease-out`; unter `prefers-reduced-motion: reduce` alle Transitions/Animationen aus.
- Kontrast: Fließtext ≥ 4.5:1; `akzent` nur für große/dekorative Elemente.
- Touch-Ziele ≥ 44×44 px. `:focus-visible`-Ring in `salbei-tief`.
- Nichts blinkt, nichts drängt, keine Badges/Zähler/Streaks.

## P1 — Modul-Schema + generischer 6-Schritt-Renderer

### Schema (`lib/module-schema.ts`, exakt so)

```ts
export type SchrittTyp =
  | "funke" | "warum" | "erleben" | "nachspueren" | "experiment" | "weitergehen";

export type TextBlock = { text: string };

export type Interaktion =
  | { art: "journal"; frage: string }
  | { art: "slider"; label: string; vorherNachher?: boolean };

export type Schritt = {
  typ: SchrittTyp;
  titel: string;
  bloecke: TextBlock[];
  audio?: string;               // z.B. "/audio/s1/01-funke.mp3"
  stilleSek?: number;           // nachspueren: Verzögerung, bevor Interaktionen erscheinen
  interaktionen?: Interaktion[];
  experiment?: { haupt: string; optional?: string };
};

export type Modul = {
  id: string;
  ebene: 0 | 1 | 2 | 3;
  thema: string;
  titel: string;
  dauerMin: number;
  voraussetzungen: string[];
  schritte: Schritt[];          // genau 6, Reihenfolge: funke, warum, erleben, nachspueren, experiment, weitergehen
};

export type LandkarteModul = {
  id: string; titel: string; thema?: string;
  status: "aktiv" | "bald"; dauerMin?: number;
};
export type Ebene = {
  ebene: 0 | 1 | 2 | 3; name: string; untertitel: string; module: LandkarteModul[];
};
export type Landkarte = {
  einstieg: { gruss: string; text: string };
  ebenen: Ebene[];
};
```

### Content-Zugriff (`lib/content.ts` + `lib/validate-module.ts`)

- `lib/validate-module.ts`: handgeschriebener Runtime-Validator (keine Dependency). `validateModul(data: unknown): Modul` prüft: alle Pflichtfelder mit korrekten Typen; `schritte` hat genau 6 Einträge in der festen Reihenfolge `funke, warum, erleben, nachspueren, experiment, weitergehen`; `bloecke` nicht leer, jeder Block hat nicht-leeren `text`; `experiment`-Feld genau beim Typ `experiment` vorhanden. Bei Fehler: `throw new Error` mit Modul-ID, Pfad und Grund.
- `lib/content.ts`: importiert `content/modules/s1.json` und `content/landkarte.json`, validiert beim Modul-Load (Import-Zeit), exportiert `alleModule: Modul[]`, `getModul(id: string): Modul | undefined`, `landkarte: Landkarte`.
- Neues Modul = neue JSON-Datei + ein Eintrag in der Import-Liste in `content.ts` — sonst kein Code.

### Text-Rendering (`components/modul/Bloecke.tsx`)

Kleiner Inline-Parser (kein `dangerouslySetInnerHTML`, keine Markdown-Lib):
- Pausen-Marker entfernen für die Anzeige: Regex `/\s*\[(kurze Pause|Pause|längere Pause)\]/g` → `""`, danach doppelte Leerzeichen zu einem zusammenziehen und `trim()`. (Die Marker bleiben in den JSON-Daten — sie sind Quelle für die Audio-Pipeline in P2.)
- `**…**` → `<strong>`, `*…*` → `<em>` (nicht-gierig, kein Verschachteln nötig).
- `\n\n` innerhalb eines Strings (kommt in `experiment.haupt` vor) → Absatztrennung.
- Jeder Block ein `<p>` mit ruhigem Absatzabstand.

### Modul-Player (`app/modul/[id]/page.tsx` + `components/modul/ModulPlayer.tsx`)

- Server-Page: `getModul(id)`, bei unbekannter id `notFound()`. `generateStaticParams` aus `alleModule`.
- Kopfbereich: Modul-Titel (h1), darunter dezent `{thema} · ca. {dauerMin} Minuten`.
- **ModulPlayer** (Client): zeigt genau einen Schritt; Zustand `schrittIndex`.
  - **Fortschritt:** 6 Punkte, aktueller gefüllt, besuchte dezent; `aria-label="Schritt {n} von 6: {titel}"`. Kein Prozentbalken, kein Druck.
  - **Navigation:** unten links Button `Zurück` (ab Schritt 2, ghost), rechts Button `Weiter` (primär, immer aktiv — jeder Schritt ist ohne Eingabe überspringbar). Auf dem letzten Schritt statt `Weiter`: Link-Button `Zur Übersicht` → `/`.
  - Schrittwechsel mit sanftem Fade (250 ms), unter `prefers-reduced-motion` ohne Animation. Fokus nach Wechsel auf die Schritt-Überschrift (h2, `tabIndex={-1}`).
  - Schritt-Überschrift = `schritt.titel` (h2).
- **Verhalten je Schritt-Typ:**
  - `funke`, `warum`, `weitergehen`: Audio-Player (falls `audio`), darunter Bloecke.
  - `erleben`: zuerst — falls im Modul irgendein Slider mit `vorherNachher: true` existiert — der **Vorher-Spür-Check** (siehe unten), dann Audio-Player, dann Bloecke (mitlesbar).
  - `nachspueren`: Audio-Player (falls `audio`) + **nur der erste Block** sofort sichtbar. Nach `stilleSek` Sekunden (Default 15) erscheinen mit sanftem Fade die restlichen Blöcke und die `interaktionen`. Bis dahin kein Hinweis, kein Countdown — nur Ruhe. (`Weiter` bleibt die ganze Zeit aktiv — die Stille ist ein Angebot, keine Sperre.)
  - `experiment`: Bloecke, dann **ExperimentKarte**.
- **Vorher-Spür-Check** (im `erleben`-Schritt, vor dem Audio, optisch dezente Karte):
  - Text: `Wenn du magst, halte kurz fest, wie du gerade da bist. Ganz freiwillig.`
  - Darunter der Slider (gleiche Komponente wie unten). Keine Pflicht, keine Validierung.

### Interaktions-Komponenten (P1 funktional, ohne Persistenz — Speicherung kommt in P3)

- **`JournalFeld`**: Label = `frage` aus JSON. Mehrzeiliges Textfeld. Hinweis darunter: `Bleibt auf diesem Gerät. Du kannst das Feld auch leer lassen.` Placeholder: `Ein Satz genügt — nur für dich.`
- **`SpuerRegler`**: `<input type="range">` 0–10, ohne Zahlenanzeige. Links/rechts die beiden Pole aus `label` (am `↔` splitten: links `angespannt`, rechts `entspannt`). `aria-label` = ganzes Label. Startwert Mitte (5), bis zur ersten Berührung als „nicht beantwortet" behandeln.
- **`ExperimentKarte`**: hervorgehobene Karte (`sand`-Ton, `rounded-2xl`): Inhalt `experiment.haupt` (mit Absätzen), darunter — falls vorhanden — `experiment.optional` als zweiter, dezenterer Abschnitt derselben Karte. Kein Merken-Button in P1 (kommt in P3).

### Audio-Player (`components/modul/AudioPlayer.tsx`)

- HTML5 `<audio>`, eigene Controls: Play/Pause-Button (min. 48 px, `aria-label` `Abspielen` / `Pausieren`), Fortschritt als `<input type="range">` (seekbar, `aria-label="Audio-Position"`), Zeitanzeige `m:ss / m:ss`.
- `preload="metadata"`. MediaSession-API: `title` = `{modulTitel} — {schrittTitel}`, `artist` = `Gebrauchsanweisung zum Menschsein`; Play/Pause-Handler registrieren (Hintergrund-/Lockscreen-Steuerung).
- Fehlt die Datei (error-Event): Player durch dezente Zeile ersetzen: `Das Audio zu diesem Schritt folgt bald. Du kannst den Text in Ruhe lesen.`
- Kein Autoplay. Beim Schrittwechsel pausieren.

### Home (`app/page.tsx`)

- Hero: `landkarte.einstieg.gruss` als h1 (Fraunces), darunter `einstieg.text`.
- Danach je `ebene` eine Sektion: Ebenen-`name` (h2) + `untertitel`, darunter Modul-Karten:
  - `status: "aktiv"` → verlinkte Karte zu `/modul/{id}`: Titel, Chip `{thema}`, Zeile `ca. {dauerMin} Minuten`, dezenter Hinweis `Modul beginnen`.
  - `status: "bald"` → nicht verlinkte Karte, abgesenkter Kontrast (aber lesbar), Chip `bald`. Kein „gesperrt"-Icon, keine Schlösser.
- Keine Fortschrittsanzeige auf Home in P1.
